# Projeto de Relatório Gerencial de Vendas

## 🧩 Descrição do Desafio

Neste desafio, o objetivo foi criar um **relatório mais elaborado no Power BI** utilizando a base **Financial Sample**, focando em aplicar conceitos de **design de relatórios**, **navegabilidade**, **interatividade** e **experiência do usuário**, indo além da simples criação de visuais.

---

## 🎯 Objetivos do Projeto

- Desenvolver um relatório estruturado e visualmente organizado  
- Aplicar navegação entre páginas utilizando botões  
- Utilizar segmentadores e botões com imagens associadas  
- Permitir a alternância entre diferentes visuais sobre o mesmo tema  
- Consolidar boas práticas de layout e usabilidade no Power BI  

---

## 📄 Estrutura do Relatório

### 🔹 Primeira Página - 📊 Sales Report

Este dashboard foi desenvolvido como parte do **Desafio do Projeto da Formação Power BI Analyst**, com foco na análise consolidada de **vendas**, **volume**, **descontos** e **custos**, utilizando a base *Financial Sample*.

- **Cartões de Indicadores (KPIs)**
  - Total de Vendas
  - Unidades Vendidas
  - Soma de Discounts
  - Média de Gross Sales
  - Soma de COGS  
  Esses indicadores fornecem uma visão rápida do desempenho geral do negócio.

- **Gráfico de Área – Soma de Sales por Mês**
  - Mostra a evolução mensal das vendas.
  - Permite identificar tendências e sazonalidade ao longo do período analisado.

- **Gráfico de Rosca – Sales por Segmento**
  - Apresenta a distribuição das vendas por segmento de mercado.
  - Facilita a comparação da participação de cada segmento no faturamento total.

- **Gráfico de Barras – Sales por Produto**
  - Exibe o desempenho de vendas por produto.
  - Permite identificar os produtos com maior volume de vendas.

- **Treemap – Sales por País**
  - Representa a contribuição de cada país no total de vendas.
  - Facilita a análise comparativa do desempenho geográfico.

O layout foi estruturado com foco em **clareza**, **navegabilidade** e **uso de KPIs**, oferecendo uma visão analítica completa e de fácil interpretação para suporte à tomada de decisão.

### 🔹 Segunda Página - 📊 Product Report

Este dashboard tem como objetivo analisar o desempenho dos **produtos**, considerando **preço de fabricação**, **volume de vendas** e **distribuição por filtros analíticos**, permitindo uma visão detalhada do portfólio.

- **Gráfico de Barras – Preço de Fabricação por Produto**
  - Apresenta o custo de fabricação de cada produto.
  - Facilita a comparação de custos entre os produtos do portfólio.

- **Gráfico de Barras – Vendas por Produto**
  - Exibe a soma de vendas por produto.
  - Ajuda a identificar os produtos com maior desempenho comercial.

- **Visual de Árvore (Decomposition Tree) – Contagem de Product**
  - Permite explorar a distribuição da contagem de produtos de forma hierárquica.
  - Possibilita análises detalhadas por produto e filtros aplicados.

O relatório foi estruturado para oferecer uma visão analítica focada em **produtos**, combinando custo, volume de vendas e exploração interativa dos dados, apoiando decisões estratégicas relacionadas ao portfólio.

### 🔹 Terceira Página - 📊 Segment Report

Este dashboard foi desenvolvido para analisar o desempenho mercado**, explorando volume, composição das vendas e impacto de categorias de desconto.

- **Gráfico Radar – Segmento por Unidade Vendida**
  - Apresenta a distribuição das unidades vendidas entre os segmentos.
  - Permite comparação visual do volume relativo de cada segmento.

- **Gráfico de Barras – Vendas por Segmento**
  - Exibe a soma de vendas de cada segmento.
  - Auxilia na identificação dos segmentos com maior participação no faturamento.

- **Gráfico Cascata – Composição das Vendas dos Segmentos**
  - Mostra a contribuição individual de cada segmento para o total de vendas.
  - Facilita a compreensão do impacto incremental de cada segmento no resultado final.

O layout do relatório foi estruturado para oferecer uma análise clara e interativa dos segmentos de mercado, combinando métricas de volume, valor e impacto de descontos para suporte à tomada de decisão estratégica.

### 🔹 Quarta Página - 📊 Resumo do Dashboard – Country Report

Este dashboard foi desenvolvido para analisar o desempenho de **vendas por país**, permitindo comparações geográficas com suporte de filtros por **segmento** e **produto**.

- **Mapa – Soma de Sales por Country**
  - Exibe a distribuição geográfica das vendas.
  - O tamanho dos marcadores representa o volume de vendas em cada país.
  - Facilita a comparação visual do desempenho entre regiões.

O relatório foi estruturado para fornecer uma visão clara e interativa do desempenho comercial **por país**, integrando filtros estratégicos que ampliam as possibilidades de análise geográfica e comercial.
